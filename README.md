gameSense Sports is a Denver, Colorado sports-technology company that builds interactive, HD video-based cognitive training tools for baseball and softball. Its core Skill Recognition Training (SRT) uses the scientifically validated method of visual occlusion to measure and teach pitch recognition, reaction time, and decision-making so athletes learn to "see" plays before they happen. The platform packages this as SRT, Mini SRT, the Hitter IQ Challenge, and Skills Camps, and serves individual athletes, coaches, parents, teams, tournament organizations, and training facilities. gameSense sells subscriptions directly to athletes (B2C) and partners with college programs, professional organizations, and youth-sports groups (B2B). The company was selected for the inaugural Techstars SportsTech Melbourne accelerator. Its web application is built on the base44 platform. It was added to the API Evangelist network as a Techstars portfolio company and enriched by the pipeline; it does not currently publish a public developer API.
